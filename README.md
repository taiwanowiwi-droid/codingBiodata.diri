# codingBiodata.diri
Deskripsi: Program ini dibuat menggunakan bahasa Python untuk menampilkan biodata, hobi, cita-cita, tinggi badan, berat badan, dan kebiasaan tidur. Program juga menampilkan hasil pengelompokan tinggi dan berat badan. Kode dapat dipelajari, dimodifikasi, dan dikembangkan menjadi lebih baik sesuai kreativitas masing-masing.
